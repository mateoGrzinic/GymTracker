# GymTracker

GymTracker je Android aplikacija za praćenje treninga. Korisnik se prijavljuje putem Firebase Authenticationa, unosi vježbe, sprema ih u Firebase Firestore bazu i može ih pregledavati na ekranu Povijest.

## Tehnologije

- Kotlin
- Jetpack Compose
- Firebase Authentication
- Firebase Firestore
- Android Studio
